# Slicer 长度测量验收 · 2026-10-04

本轮仅继续 Slicer 方案；未修改 Python + HTML 修订版及 WRONG 归档。

## 功能和检查

新增原生两点长度测量、端点修正、结束放置、当前影像测量清除与 JSON 导出。测量引用源体节点，随其变换计算世界端点坐标；切换影像时隐藏其他影像的线。

`results.json` 的 16 项专项检查均通过，包括无影像禁用、放置模式类型与目标节点、源引用、未完成测量、5 mm 已知距离、LPS 转换、10 mm 端点修正、缩放变换后的 20 mm 距离、导出字段、不同影像之间的隐藏/恢复以及节点与观察器清理。

原有 52 项 MR 回归本轮再次通过，见 `../review-20261001-v2/results.json`。这份报告含前后源 DICOM 一致性检查。本轮没有重新进行全部 CT 工作流验收，也没有同患者 CT/MR 配准验收。

## 桌面复现

1. 使用 Windows 文件关联打开根目录 `启动 CT3D.bat`，进入 CT3D 模块。
2. 通过实际文件夹选择和载入按钮打开用户 MR，确认四宫格与新增测量面板。
3. 第一次真实鼠标测试发现 `StartPlaceMode` 会将放置类型初始化为普通 Fiducial，自动数值检查没有覆盖这一点。修复为启动模式后明确选择 MarkupsLine，并增加放置类型专项检查。
4. 新开独立 Slicer 测试窗口，使用 `tools/prepare_measurement_ui.py` 仅读入同一 MR，避免反复索引；实际鼠标点击新建测量和轴位两个端点。切片标签、三维标签与面板均显示 59.15 mm。此阶段不是根目录 BAT 启动，启动器路径已在步骤 1 单独复现。

## 边界

数值是世界坐标中的直线距离；屏幕小数位不是采集精度。JSON 不含身份/UID/源路径，但不包含完整变换，不能替代 MRB 场景保存。当前没有角度、面积、体积测量或临床精度评审。
