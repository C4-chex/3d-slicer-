# CT3D 使用说明

CT3D 是运行在 Windows 本机 3D Slicer 中的医学影像浏览与手动三维建模模块。它使用 Slicer 的 DICOM、ITK/GDCM 与 VTK 能力，不需要网页浏览器或网络连接来浏览本地影像。

当前版本已用真实 MR 和 CT 样本核验基础载入、几何和像素值。CT/MR 同患者软件配准尚未实现；配准铺垫和独立 CT 代码、样本及验收记录见 `ct part`。所有功能用于研究与科研辅助，不用于正式诊断、治疗决策或手术规划。

## 1. 启动

1. 确认本机已安装 3D Slicer 5.12.4。启动器当前配置的位置是 D:\3dslicer\3D Slicer 5.12.4\Slicer.exe。
2. 双击项目目录中的 启动 CT3D.bat。
3. 等待 Slicer 打开并切换到 CT3D 模块。也可在 Slicer 顶部模块选择区搜索 CT3D。
4. 若提示找不到 Slicer，打开 启动 CT3D.bat 并检查 SLICER 路径是否和安装位置一致。

旧的 Python + HTML 失败原型已保存在 D:\WRONG\python-html-failed；本说明和当前代码属于原生 Slicer 版本。

## 2. 导入和载入影像

### 导入文件夹

1. 点击 导入 DICOM 文件夹…。 
2. 在文件夹选择窗口中选择包含 DICOM 切片的文件夹；可以选择含子文件夹的顶层目录。
3. 等待状态栏提示扫描完成。此时程序读取元数据并建立本机 DICOM 索引，尚未解码整套影像像素。
4. 在 待载入序列 下拉框中选择目标序列。每项显示序列编号、模态、序列描述、切片数和矩阵尺寸。
5. 展开 数据质量与输出 检查该序列的几何和提示。
6. 确认没有阻止载入的错误后，点击 载入选中序列。载入完成后出现轴位、冠状位、矢状位和三维视图。

CT3D 使用 Slicer 本机 DICOM 数据库。当前导入函数默认不复制 DICOM 文件；源影像按只读方式使用，数据库索引会写入本机。优先使用 Slicer 当前打开的数据库；没有可用数据库时使用 D:\3d - 1\CT3D\Data\DICOM。该索引目录不是原始影像备份。

### 选择与切换

- 选择候选序列只更新候选信息，不会立即改变当前影像。点击 载入选中序列 才会切换。
- 出现 需处理 标记或质量错误时，载入按钮会禁用。按错误提示检查数据，不要把不同几何或不同采集的切片手工合并。
- 再次载入同一文件集合会复用体数据并复位视图。切换序列时会保留会话和手动分割以便返回；连续载入多个大型序列会增加内存占用。
- 载入失败时会撤回本次新建的场景节点并恢复先前显示。源 DICOM 不会因此被改写。

## 3. 数据质量与输出面板

该面板用于在解码整套影像前检查序列元数据：

| 项目 | 用途和解释 |
| --- | --- |
| 模态、切片数、矩阵 | 确认 CT/MR 类型、切片数量和图像行列尺寸。 |
| 像素间距、切片间距范围 | 查看空间采样间距，单位 mm。层间距不均匀或差异较大时，应谨慎解释重建切面与三维外观。 |
| 强度单位 | MR 强度不是 HU。CT 在显式声明 HU，或满足单能量、ORIGINAL、非 LOCALIZER 的 DICOM 缺省规则，并且每张切片的变换参数与序列检查通过时，才启用 CT 专用预设。仍请阅读检查提示。 |
| 错误 | 会阻止载入，例如矩阵或方向不一致、必要几何缺失或重复位置等。 |
| 提示 | 说明风险或功能边界。能载入不代表适合测量、诊断或手术规划。 |
| 烧录注释标记 | 读取 DICOM 对影像内文字的声明。标记 YES 时阻止四视图截图导出；UNKNOWN 时仍需人工检查图像边缘。 |

点击 导出序列质量报告… 可保存 JSON。报告包含模态、切片数、矩阵、间距、CT HU 元数据资格及错误/提示，不包含患者姓名、患者 ID、序列 UID 或源文件路径。

## 4. 四视图阅片与定位

影像载入后，视图区是 2×2 四宫格：左上轴位、右上冠状位、左下矢状位、右下三维体渲染。三张切片共享同一患者坐标位置，视图边缘有解剖方向标识。

| 操作 | 详细方法 | 用处 |
| --- | --- | --- |
| 逐层浏览 | 将鼠标放在任一切片窗格内滚动滚轮。 | 沿当前切面方向逐层浏览。层间实际距离取决于影像采集。 |
| 十字线联动定位 | 保持 十字线联动定位 勾选，在切片窗格按住 Shift 并移动鼠标。 | 移动十字线并联动三个切面到同一空间位置；取消勾选可隐藏十字线及切面交线。 |
| 三维中显示切片 | 勾选 在三维中显示切片平面。 | 在三维视图叠加三张切片平面，方便看清当前切面位置；取消后隐藏。 |
| 四视图复位 | 点击 复位四视图。 | 复原标准方向、居中、缩放和三维相机；保留窗宽窗位和裁剪。 |
| 标准 MPR | 平面模式选择 标准解剖方向（MPR 重建）。 | 将三个切面调整为标准轴位、冠状位、矢状位；斜向采集需要重建切面，显示平滑不等于分辨率提高。 |
| 采集方向 | 平面模式选择 按原始采集方向对齐。 | 切面旋转到采集平面，并从实际体素位置开始浏览。带非线性空间变换时不能用单一平面代表采集方向，程序会禁用并退回标准 MPR。 |
| 三切面同尺度 | 勾选 三切面按相同比例显示。更改后视图会重新适配。 | 使三张切片使用相同 mm/屏幕像素比例，减少窗格大小不同造成的视觉误差。取消后各窗格分别适配。 |
| 插值显示 | 勾选 二维平滑显示 使用线性显示插值；取消后查看最近邻采样。 | 平滑模式减少像素块感；最近邻模式更易观察原始像素格。二者都不修改源像素，也不增加细节。 |

三维窗格通常可用鼠标左键拖动旋转、滚轮缩放、中键拖动平移；如 Slicer 交互器设置被更改，实际鼠标映射以当前 Slicer 为准。

## 5. 窗宽、窗位和强度显示

1. 展开 阅片 · 定位与显示 面板。
2. 在 窗宽 或 窗位 输入数值，按 Enter 或移出输入框后生效。窗宽控制显示灰阶范围宽度，窗位控制该范围中心。
3. 点击 自动对比度 恢复自动灰阶设置。
4. MR 使用序列自身的强度单位；不要把 MR 数值解释成 HU。
5. CT 软组织、CT 肺、CT 骨按钮只对通过 CT HU 元数据与序列检查的已载入 CT 启用。它们分别设置常见 CT 窗宽/窗位；MR 上这些按钮不可用。

候选序列下拉框与当前显示序列是分开的。选择新的候选后，窗口状态会提醒尚未切换；点击载入按钮才会改变当前影像。

## 6. 三维体渲染与裁剪

体渲染是把体素数据显示成三维影像，并不等于生成器官表面模型。

| 控件 | 操作与作用 |
| --- | --- |
| 显示三维体渲染 | 勾选或取消勾选，显示/隐藏三维体渲染；二维切片不受影响。 |
| 体渲染预设 | 选择 与二维对比度同步，或选择当前模态可用的本机预设。MR 可选 MR 通用（需按序列调整）或 MR 最大强度投影。CT 预设仅在 HU 元数据门槛通过后开放。 |
| 裁剪开关 | 勾选 仅显示裁剪框内的体影像 启用 ROI 裁剪。首次开启会建立覆盖全数据的框。 |
| 裁剪框与手柄 | 勾选 显示裁剪框与拖动手柄，然后在三维视图拖动边界面或手柄调整显示范围。 |
| 框中心移至十字线 | 把当前 ROI 中心移到十字线位置；再拖动边界调整范围。 |
| 恢复完整范围 | 将 ROI 重置为覆盖整个体数据。 |

ROI 只改变三维体渲染的显示范围，不剪切原始切片或分割。

## 7. 手动三维结构建模

这里的三维模型必须先由操作者手动勾画分割生成。CT3D 不会自动识别器官或病灶。模型正确性取决于分割边界。

### 勾画结构并生成表面

1. 载入目标序列，展开 三维结构建模（手动分割）。
2. 点击 创建结构并开始分割。CT3D 会建立空结构并打开 Slicer 的 Segment Editor（分割编辑器）。
3. 在 Segment Editor 选择要编辑的结构和效果，例如 Paint、Draw 或 Erase。
4. 在轴位、冠状位或矢状位切片上勾画；先用小区域确认方向和位置，再继续扩展。使用编辑器的撤销/重做修正笔画。
5. 完成勾画后，从 Slicer 顶部模块选择器切回 CT3D。
6. 点击 生成 / 更新三维表面。闭合表面会出现在三维窗格；若为空，回到切片检查是否有已提交的分割像素。

### 保存与导出

- 点击 保存可继续编辑的分割…，保存为 .seg.nrrd；此格式保留分割数据，可继续编辑。
- 若影像/分割带空间变换，单独保存 .seg.nrrd 会失去世界坐标关联，CT3D 会阻止该操作。按提示用 Slicer 顶部 Save 保存完整 .mrb 场景，包含影像、分割和变换。场景可能带身份信息，只适合本机保存或去标识化后分享。
- 点击 导出 STL 表面模型… 并选输出文件夹。每个非空分割会生成一个 STL，使用毫米和 LPS 坐标。STL 只有表面几何，不含影像或可编辑标签；继续编辑请保留 .seg.nrrd 或完整场景。
- 导出前逐个检查结构边界、位置、方向和表面外观。CT3D 不会自动校正错误勾画。

## 8. 文件导出与隐私检查

| 按钮 | 输出 | 重要说明 |
| --- | --- | --- |
| 导出序列质量报告… | 单个 JSON。 | 仅包含非身份类质量及几何信息；确认保存到合适的本机位置。 |
| 导出四视图截图与参数… | 四视图 PNG 和同名 JSON。JSON 记录模态、体素几何、切片矩阵、窗宽窗位、相机和裁剪等显示参数。 | PNG 隐藏控制条等软件界面并保留固定方向标签。标记 YES 时会拦截；其余情况程序要求操作者确认，并要求检查影像像素边缘烧录的姓名、ID、检查号。程序不会自动去除烧录在像素里的文字。 |
| 保存可继续编辑的分割… | .seg.nrrd。 | 若有空间变换，使用完整 .mrb 场景保存。 |
| 导出 STL 表面模型… | 每个非空分割一个 STL，mm，LPS。 | 不包含源影像、分割标签或诊断判断；导入其他软件后需核对单位与方向。 |

PNG 和 JSON 作为一对写入；常规写入失败时程序会尝试回滚已有文件。但这不保证在断电或系统崩溃时具备事务性。

## 9. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 没有候选序列 | 检查目录里是否是可读 CT/MR DICOM，并重新选择包含影像的上级目录导入。 |
| 质量错误导致不能载入 | 展开质量面板阅读错误。常见原因是混合矩阵、方向、位置或采集类型；从原始来源重新导出完整单一序列。 |
| 冠状/矢状面模糊或呈台阶 | 检查原始层间距；可关闭平滑切换最近邻查看像素采样。插值无法补回未采集的细节。 |
| 三维窗格空白 | 检查影像是否载入、三维体渲染是否勾选，并尝试本模态的预设。若渲染初始化失败，状态栏会给出原因，二维浏览仍可能可用。 |
| 截图导出被阻止 | 若序列 Burned In Annotation 为 YES，这是防止泄露烧录文字的保护。不要绕过后分享；如确需输出，应先按机构流程处理去标识化。 |
| 分割不能单独保存 | 若提示空间变换，使用完整 .mrb 场景保存。 |
| 想恢复初始阅片视图 | 点击 复位四视图；不会清除窗宽窗位或裁剪。 |

## 10. 验收状态和功能边界

- 2026-10-01 使用本机 3D Slicer 5.12.4 和 143 个 MR 文件完成 52 项自动自检，全部通过；源 DICOM 前后 SHA-256 一致。范围包含 MR 载入、几何和像素核对、四视图、联动定位、裁剪、导出失败回滚、分割编辑接口及序列切换回滚。详细结果见 [验收记录](verification/review-20261001-v2/验收记录.md) 与 [结果 JSON](verification/review-20261001-v2/results.json)。
- 2026-10-01 使用开源 Philips CT 体模序列完成 HU 与 dcm2niix 参考 NIfTI 核对：140 层、512×512、1 mm；Slicer 载入值与参考在 284 个物理坐标采样点上最大差为 0 HU，几何映射误差低于 0.00003 体素；软组织窗、HU 范围、源文件 SHA-256 检查均通过。8 项 CT HU 规则测试通过。结果见 [CT 工作流报告](ct%20part/validation/ct-workflow.json)、[序列索引报告](ct%20part/validation/dataset-inspection.json)。同仓库另有 28 层 GE 人体头部 CT，但图像类型和采集编号混杂，当前安全规则拒绝将整组堆叠；因此本轮验证不宣称人体 CT 阅片通过，也不代表胸腹部 CT 或临床准确性已经验收。
- CT 样本及 BSD-2-Clause 许可保存在 `ct part/source-dcm_qa_ct`；CT 专属 HU 单位规则在 `ct part/CT3DCTLib`；同患者 CT/MR 配准设计约束在 [配准设计](ct%20part/配准设计.md)。配准还未实现。
- 已测得独立 Slicer 窗口左右栏宽比例约 0.619:1，目标约 0.618:1；验收四视图各窗格约 563×396 或 562×396 像素。
- 没有 AI 自动分割、诊断、病灶检测、PACS、DICOM SEG 导出、测量工具、加载取消、内存预算或自动降采样。
- 会话保留旧体数据和分割以支持返回，因此打开很多大型序列会增加内存占用。重要工作请及时保存场景。
- NV-Reason-CT 是独立参考项目；当前 CT3D 未调用其推理代码、权重或网络服务。
- CT3D 用于本地科研阅片和方法开发，不替代临床工作站、放射科医师判断或正式手术规划软件。
